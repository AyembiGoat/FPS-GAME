# FPS UI Reference Study & Design Specification

This document records the shipped AAA game UI references studied before writing any UI code, synthesises the craft patterns shared across modern tactical shooters, and defines the complete visual, typographic, colour, surface, motion, icon, and audio specification for **Shoot House**.

All 44 reference screenshots saved during research live locally in gitignored `reference/ui/` (`01` through `44`), covering 7 screen categories across 15 shipped titles and series. Every image was opened and visually inspected before specifying this design.

## 2. Cross-Game Synthesis: What Shipped Tactical Shooters Share

1. **Open Central Sightlines & Peripheral Anchoring**: Across _MW 2019_, _BF6_, _Titanfall 2_, _Valorant_, and _Halo Infinite_, the central 65–75% of the viewport is strictly reserved for the 3D world, dynamic crosshair, and transient hit markers. Permanent HUD elements hug a consistent outer safe frame (`32px–44px` inset) and use soft directional dark scrims + `1px` hairlines rather than heavy opaque cards.
2. **Worst-Case Daylight Legibility**: Shoot House has bright sunlit concrete, pale plywood walls, and blue sky (`playtest/before/01-spawn.png`). Pure white text without backing disappears against sky/plywood. Every HUD element needs a feathered dark gradient backing or `1px` dark contrast stroke/shadow so it reads equally over sunlit sky and shadowed interiors (_Deus Ex_ legibility board, _Valorant_ crosshair outline, _MW 2019_ corner scrims).
3. **Condensed Tabular Numerals + Clean Grotesque UI Copy**: Every studied military/tactical FPS pairs a condensed grotesk for big numerals, timers, ammo counts, and tracked uppercase headers (_MW 2019_ ITC Conduit / Bio Sans, _CS2_, _BF6_, _The Finals_) with a clean neutral humanist/geometric grotesk for settings labels, descriptions, and key hints. `font-variant-numeric: tabular-nums` prevents timers and ammo counters from jittering horizontally as digits tick.
4. **Restrained Graphite Palette + Single Tactical Accent**: Surfaces are layered cool gunmetal/slate (`#0B0E13` to `#1B222C`), muted steel borders (`rgba(226, 234, 244, 0.14)`), crisp bone-white primary ink (`#EEF2F6`), and **one** signature tactical accent (warm brass/amber `#E5A93C`) used sparingly for active indicators, focus bars, target completion pips, and primary confirmations—distinct from semantic confirm (`#49C687`), warning/low-ammo (`#F08C3A`), and empty/danger (`#E5534B`).
5. **Two-Column Settings Grammar with Zero Native Inputs**: _BO6_, _BF6_, _R6 Siege_, _Apex_, and _Titanfall 2_ all use horizontal top tabs, a left list of custom controls (filled sliders with numeric readouts, `< Value >` steppers, segmented toggles, colour swatches) with per-row reset buttons, and a right-hand contextual inspector showing a 1-line description (plus live crosshair preview when editing crosshair settings).
6. **Motion That Answers on Frame 1**: Entrances use fast deceleration (`cubic-bezier(0.22, 1, 0.36, 1)`, `160–280ms`), exits are ~35% shorter (`110–160ms`), button presses respond under `90ms`, hit markers snap and clear in `<220ms`, and `transform` + `opacity` carry all movement so layout never recalculates during gameplay.

## 3. Design Specification for _Shoot House_

### 3.1 Aesthetic Identity

**Precision Range Telemetry** — grounded military-industrial range instrumentation inspired by _Call of Duty: Modern Warfare (2019)_, _Battlefield 6_, _Rainbow Six Siege_, and _Valorant_. Dark anodized gunmetal glass, `1px` machined hairlines, subtle corner ticks, crisp condensed tabular numbers, and a warm cartridge-brass accent (`#E5A93C`) sitting cleanly over the sunlit plywood and concrete of **Shoot House**. Zero sci-fi hexagons, zero fake currencies/ranks/modes, zero cartoon bevels.

### 3.2 Colour Tokens (`src/game/ui/tokens.css`)

All UI colours flow from CSS custom properties:

- **Neutrals & Surfaces**:
  - `--ui-bg-scrim-strong`: `rgba(8, 11, 15, 0.84)` (pause/settings backdrop wash)
  - `--ui-surface-0`: `rgba(11, 15, 20, 0.72)` (HUD peripheral gradient/plate base)
  - `--ui-surface-1`: `rgba(16, 21, 28, 0.86)` (menu rows, settings container)
  - `--ui-surface-2`: `rgba(24, 31, 41, 0.92)` (elevated cards, active control track, keycaps)
  - `--ui-surface-hover`: `rgba(34, 44, 58, 0.95)` (hovered/focused interactive surface)
- **Ink / Text**:
  - `--ui-ink-primary`: `#EEF2F7` (primary numerals, titles, active labels)
  - `--ui-ink-secondary`: `#A6B2C2` (unfocused menu labels, setting descriptions, reserve mag)
  - `--ui-ink-muted`: `#6C7889` (key hints, section metadata, disabled/default reset icons)
  - `--ui-ink-inverse`: `#0B0E13` (text on solid primary accent fill)
- **Borders & Hairlines**:
  - `--ui-edge-subtle`: `rgba(230, 238, 248, 0.11)`
  - `--ui-edge-strong`: `rgba(230, 238, 248, 0.28)`
  - `--ui-edge-highlight`: `rgba(255, 255, 255, 0.48)` (top specular edge / active focus border)
- **Accent & Semantic Tokens**:
  - `--ui-accent`: `#E5A93C` (warm tactical cartridge brass — used sparingly on active tab bar, focused row left bar, completed target segments, primary CTA accent)
  - `--ui-accent-soft`: `rgba(229, 169, 60, 0.16)`
  - `--ui-accent-glow`: `rgba(229, 169, 60, 0.34)`
  - `--ui-confirm`: `#47C284` (run complete badge / target-down confirmation)

### 3.4 Spacing, Grid & Safe Margins

- **4px base unit** (`4, 8, 12, 16, 24, 32, 44, 64px`).
- **HUD Safe Margin**: `clamp(20px, 2.6vw, 40px)` inset on all four edges (`--ui-safe-x`, `--ui-safe-y`). On ultrawide viewports (`aspect-ratio > 21/9`), HUD horizontal inset clamps to keep peripheral telemetry comfortably within a `1920px`–`2200px` central reading corridor so the player never has to turn their head.
- **Menu & Settings Frame**: Max content width `1120px`, horizontally centered with `clamp(24px, 5vw, 64px)` side padding; two-column split on Settings (`minmax(0, 1.55fr)` controls column + `minmax(260px, 0.9fr)` sticky inspector card). Responsive down to `1280x720` without clipping or scroll traps.

### 3.5 Surfaces, Borders & Depth Hierarchy

Three restrained surface levels:

1. **HUD Scrim Plate (Level 0 — zero `backdrop-filter`)**: Directional linear gradient (`linear-gradient(180deg, rgba(12,16,22,0.68), rgba(8,11,15,0.82))`), `1px` border (`--ui-edge-subtle`), `1px` top inner highlight (`inset 0 1px 0 rgba(255,255,255,0.12)`), soft drop shadow (`0 10px 24px rgba(0,0,0,0.34)`), crisp `2px` radius with `6px` machined corner tick accents on primary modules. Never uses `backdrop-filter` on per-frame updating HUD elements.
2. **Overlay / Modal Surface (Level 1 — sparse `backdrop-filter`)**: Applied **once** on the static full-screen pause/menu overlay backdrop (`backdrop-filter: blur(8px) saturate(0.88)`), paired with a radial/directional dark grade so the live Three.js Shoot House remains atmospheric behind Pause, Settings, and Controls.
3. **Interactive Control / Keycap Surface (Level 2)**: `--ui-surface-2` with `1px solid var(--ui-edge-strong)`, `inset 0 1px 0 rgba(255,255,255,0.08)`, `inset 0 -1px 0 rgba(0,0,0,0.45)`. Keycaps add a `2px` bottom bevel (`box-shadow: 0 2px 0 rgba(0,0,0,0.55)`) so keys read immediately as physical caps.

### 3.6 Glow & Stateful Light

Glow is strictly transient or stateful:

- Focused/selected menu button: `3px` left `--ui-accent` bar + `box-shadow: 0 0 18px -4px var(--ui-accent-glow)`.
- Target-down segment & Run Complete sweep rule: brief `260ms` brass/emerald luminance pulse that settles back to crisp solid fill.
- Dry-fire / empty magazine (`0 / 7`): sharp crimson edge flash (`--ui-danger`) + subtle horizontal micro-shake (`3px`, `160ms`) paired with explicit `EMPTY` badge and `[R] RELOAD` prompt.

### 3.7 Motion Tokens & Reduced-Motion Behaviour

- `--ui-ease-out`: `cubic-bezier(0.22, 1, 0.36, 1)` (primary responsive deceleration — answers on frame 1)
- `--ui-ease-in`: `cubic-bezier(0.4, 0, 1, 1)` (fast exits)
- `--ui-ease-in-out`: `cubic-bezier(0.45, 0, 0.2, 1)` (tab underline & continuous interpolations)
- `--ui-dur-instant`: `85ms` (button active press, keycap depress)
- `--ui-dur-fast`: `150ms` (hover/focus highlight, screen exit, hit marker snap)
- `--ui-dur-base`: `220ms` (panel/tab entrance, ammo tick pop, event feed slide)
- `--ui-dur-slow`: `340ms` (title reveal, run-complete banner sweep, intro dissolve)
- `--ui-stagger`: `38ms` per menu item / stat block (total sequence always `< 320ms`).
- **Reduced Motion** (`prefers-reduced-motion: reduce` OR the in-game **Reduced Motion** setting): collapses spatial transforms (`translate`, `scale`, camera sway amplification, banner sweep wipe) to `0px` / `1` and uses short `100ms` opacity cross-fades while keeping every state change clear.

### 3.8 Iconography & Weapon Vector Art (`src/game/ui/icons.ts`)

- Every icon is hand-authored inline SVG on a **`20x20` pixel grid** (`viewBox="0 0 20 20"`) with consistent **`1.6px` stroke weight**, squared-miter/clean `round` joins, and `currentColor` inheritance: Play reticle/chevron, Resume, Restart cycle, Settings gear/sliders, Controls keycap, Quit return arrow, Check, Reset-to-default counter-arrow, Volume speaker, Lean-left / Lean-right angle indicators, Sprint chevrons, Target silhouette, Left/Right mouse button diagrams.
- **M1911 Side-Profile Silhouette**: Clean custom vector (`viewBox="0 0 168 96"`) depicting the classic Government Model M1911A1 profile — slide serrations, front & rear iron sights, ejection port cutout, external hammer spur, beavertail grip safety, trigger guard cutout, angled grip frame, and baseplate — matching the gun in the player's hands.

### 3.9 UI Sound Grammar (`src/game/audio/sounds.ts`)

Synthesised procedurally through the existing Web Audio engine (routed through the live **Master Volume** gain node, zero external audio assets, very quiet relative to gameplay gunfire):

- **`uiHover`**: Ultra-short (`18ms`) damped band-pass tick (`1.9 kHz`, peak gain `~0.025` of shot) when pointer enters or arrow focus moves to a new interactive row (throttled `45ms` so sweeping never buzzes).
- **`uiSelect`**: Crisp two-transient mechanical switch (`2.4 kHz` click + `620 Hz` body, `42ms`) on menu click, tab switch, or stepper change.
- **`uiBack`**: Soft descending two-tone damped thock (`540 Hz -> 360 Hz`, `55ms`) on Escape, Back, or closing a submenu.
- **`uiConfirm`**: Clean harmonic double-stop (`660 Hz` + `990 Hz` fifth with fast exponential decay, `110ms`) when starting Play, restarting a run, or completing all 10 targets.

## 4. Screen-by-Screen Functional Blueprint

1. **Intro Sequence & Live Title Screen**:
   - On initial load in normal play mode (`?bot`, `?auto`, `?materials`, `?weapon` bypass directly to their modes so automated tests and inspection views work undisturbed), a short (`~1.1s` skippable on any click/key) range-readiness intro sweeps open over the live Three.js canvas (`SHOOT HOUSE // LIVE FIRE COURSE · 32M × 24M · 10 STEEL TARGETS · M1911 .45 ACP`) and cross-dissolves into the **Title Screen**.
   - Behind the Title Screen, the camera glides slowly along a curated vantage path overlooking Shoot House behind a directional dark-slate grade.
   - Left-aligned lockup (`SHOOT HOUSE` + concise tactical range subtitle) and staggered vertical menu: **Play**, **Settings**, **Controls** (every button real and wired). Full keyboard (`ArrowUp`/`ArrowDown`/`W`/`S`, `Enter`/`Space`) and mouse support, plus bottom keycap legend.
2. **In-Game HUD**:
   - **Top Objective Tracker**: Centered compact module showing `TARGETS` (`0 / 10` up to `10 / 10`), a **10-segment progress bar** (one segment per steel target, lighting up with a crisp brass pulse as each drops), and the live tabular **Run Timer** (`00:00.00`, starting on the player's first action/movement/shot or run start and freezing on the 10th target hit).
   - **Bottom-Right Weapon & Ammo Panel**: Large animated current round count (`7`), `/ 7` magazine capacity, `M1911` + `.45 ACP` label, custom M1911 side-profile SVG silhouette, **7 individual round pips** that empty with a crisp downward/fade tick on each shot, low-ammo warning (`<= 2` rounds: amber tint + `LOW` badge), empty state (`0` rounds: crimson dry-fire flash + `EMPTY` badge), and a smooth linear + weapon-bar **Reload Progress Indicator** driven directly by `weapon.reloadLeft / M1911.reloadTime` (`2.1s`) that snaps back to 7 full pips on `reload-end`.
   - **Contextual Reload Prompt**: Positioned cleanly below the central sightline when `mag <= 2` (amber `[R] RELOAD`) or `mag === 0` (urgent crimson `[R] RELOAD — EMPTY`), hidden while actively reloading or full.
   - **Dynamic Crosshair**: Center dot + 4 crisp `1px`-outlined hairlines whose gap expands smoothly with horizontal player speed, airborne state (`!player.onGround`), and weapon recoil/cooldown, settling tightly when still, and fading smoothly to `opacity: 0` as `weapon.aim` approaches `1` (iron sights). Respects live **Crosshair Colour** and **Crosshair Size** settings.
   - **Hit Marker**: Sharp diagonal `X` ticks around screen center (`< 220ms` snap-scale + fade) on `target-down`, using a distinct stronger double-tick crimson/brass **Target Down** burst when a steel target drops.
   - **Event Feed**: Upper-right / mid-right stacked tactical feed sliding in when each target falls (`TARGET DOWN` + exact distance in metres computed from player eye to hit point, e.g. `14.8 m`, plus target count `4/10`), stacking cleanly and fading out after `3.2s`.
   - **Run Complete Banner**: When `targetsDown === 10`, a _Modern Warfare_ / _Valorant_-inspired horizontal sweep band animates across the upper-middle viewport displaying **COURSE CLEARED**, real **Time**, **Shots Fired**, **Accuracy** (`hits / shotsFired`), and a live **Reset Countdown** bar & numeral tracking `state.resetIn` (`3.0s -> 0.0s`) before folding away cleanly on `targets-reset`.
   - **Stance Indicators**: Quiet peripheral badges near bottom-center/left showing **Lean Left**, **Lean Right**, and **Sprinting** only while active (`Math.abs(player.lean) > 0.05` or active sprint).
3. **Pause Menu**:
   - Opens seamlessly whenever pointer lock is released during active play (and closes instantly onto pointer lock on **Resume**). Blurs and dims the paused Shoot House viewport behind it and displays current run progress (`Targets`, `Time`, `Accuracy`).
   - Entries: **Resume**, **Restart Run**, **Settings**, **Controls**, **Quit to Title**.
4. **Settings Screen** (accessible from both Title and Pause without losing run state):
   - Animated horizontal tabs: **Controls**, **Gameplay & View**, **Audio**, **Interface** (each with clear section headers, custom controls, 1-line focus description in the right-hand inspector, per-setting reset button when changed from default, and `[R] Reset Tab` / `Reset All`).
   - All 8 required settings persisted in `localStorage` (`fps.settings.v1`) and applied live:
     1. **Mouse Sensitivity** (`0.20x` – `3.00x`, default `1.00x`)
     2. **ADS Sensitivity** (`0.25x` – `2.00x`, default `1.00x` relative to hipfire zoom scaling)
     3. **Field of View** (`65°` – `105°`, default `78°`, updates `camera.fov` + projection matrix live)
     4. **Master Volume** (`0%` – `100%`, default `80%`, updates Web Audio master gain live)
     5. **Crosshair Colour** (White, Brass, Cyan, Green, Red — with live crosshair preview widget)
     6. **Crosshair Size** (`Small`, `Medium`, `Large` / `0.75x` – `1.50x` — live in preview & HUD)
     7. **HUD Scale** (`85%` – `120%`, default `100%`, scales HUD modules cleanly via `--ui-hud-scale`)
     8. **Reduced Motion** (`Off` / `On`, defaults to OS `prefers-reduced-motion` if unset)
5. **Controls Screen**:
   - Grouped under clean tactical section headers (**Movement**, **Combat**, **Stance**, **System**), listing every real action (`Move Forward/Back/Left/Right`, `Sprint`, `Jump`, `Fire`, `Aim Down Sights`, `Reload`, `Lean Left`, `Lean Right`, `Pause / Menu`) with custom drawn physical keycaps (`W`, `A`, `S`, `D`, `Shift`, `Space`, `R`, `Q`, `E`, `Esc`) and custom SVG Left/Right Mouse Button diagrams.
